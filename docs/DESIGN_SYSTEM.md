# Nusantara Atelier — 设计规范（Design System）

> 版本：v1.0 · 2026-08-26 · 参照 ArchDaily 的简约现代语言
> 适用：全站所有页面与组件。新组件必须遵守本规范。

---

## 1. 设计语言

**关键词：编辑感 · 克制 · 网格 · 单点缀色**

像一本建筑杂志：大量留白、细线分割、信息层级靠字体大小和字重而非色块。照片是唯一的主角，界面永远退到照片后面。

## 2. 色彩

| 角色 | 值 | 用途 |
|------|-----|------|
| `paper` | `#FFFFFF` | 页面基底 |
| `paper-soft` | `#FAFAFA` | 次级区块背景 |
| `ink` | `#141414` | 正文/标题（近黑） |
| `ink-2` | `#6B6B6B` | 次要文字 |
| `ink-3` | `#9A9A9A` | 辅助文字/占位 |
| `line` | `#E5E5E5` | 细分割线/卡片描边（1px） |
| `accent` | `#E4022B` | **唯一点缀色**：关键链接、激活态、CTA、重点数字 |

规则：
- 金色（#C9A96E）全面退役，由 accent 红取代；红色面积任何时候不超过一屏的 5%
- 禁用渐变底色块、禁用彩色卡片底；强调用红色**文字或 1px 线**，不用红色填充大区块（主 CTA 按钮除外）
- 深色模式不做

## 3. 字体与排版

- 字体栈（全局无衬线）：`"Helvetica Neue", Helvetica, Inter, Arial, "PingFang SC", "Microsoft YaHei", sans-serif`
- **不再使用衬线字体**（之前的 Georgia 标题栈废弃）
- 层级：
  -  eyebrow 小标签：11–12px / 全大写 / 字距 0.12em / ink-2 或 accent
  - H1：40–56px / 字重 600 / 字距 -0.02em
  - H2：28–36px / 字重 600
  - 正文：15–16px / 行高 1.7 / ink
  - 辅助文字：13px / ink-2
- 数字与价格：tabular-nums（`font-variant-numeric`），千分位
- 换行：标题 `text-balance`，正文 `text-pretty`（沿用既有约定）

## 4. 图标

- 统一**线性图标**：1.5px 描边、圆角端点、无填充、20×20 视框
- 图标即 inline SVG（零依赖），集中放 `components/icons.tsx` 统一导出
- 禁止 emoji 当功能图标（服务四卡的 🏛️🔨🛋️🗝️ 全部换成线性图标）
- 图标颜色跟随文字（currentColor），激活态用 accent

## 5. 组件规则

- **卡片**：直角（radius 0，至多 2px）、1px `line` 描边、无阴影或极浅阴影；hover 仅图片轻微缩放（1.03）
- **按钮**：主 CTA = accent 红底白字直角；次按钮 = 1px ink 描边白底；禁用圆角药丸
- **chips/筛选器**：1px `line` 描边直角小标签，激活态 = accent 文字 + accent 描边，不填充
- **分割线**：1px `line`，不用色块分区
- **导航**：白底 + 底部 1px `line`，品牌名无衬线 600，语言切换器用文字按钮（ID / EN / 中文），激活下划线 2px accent
- **案例卡片版式**（参照 ArchDaily）：大图 → 项目名（600）→ 一行 meta：`地点 · 风格 · 面积`（ink-2，13px）→ 有造价时一行造价数据
- **详情页 meta**：ArchDaily 式定义行：`面积: 600 ㎡` / `风格: 现代` / `硬装造价: 5500 元/㎡`（标签 ink-3 + 值 ink，行间 1px 线）

## 6. 布局

- 内容最大宽度 1200px，页边距 24px（移动端 16px）
- 屏次之间用留白分隔（96–128px），不用背景色带分区
- 网格：案例画廊 3 列（桌面）/ 2 列（平板）/ 1 列（手机），间距 24px

## 7. 迁移清单（现有 → 新规）

| 现有 | 改为 |
|------|------|
| 暖金 #C9A96E 点缀 | accent #E4022B |
| 衬线标题（Georgia 栈） | 无衬线 600 |
| 圆角卡片/药丸 chips | 直角 + 1px 线 |
| emoji 服务图标 | 线性 SVG 图标 |
| 渐变占位图 | 保留（图片加载兜底），色相改中性灰 |
