# Phase 3 PRD — 印尼本地材料 SKU 库 + 精确 BOM 报价

> 版本：v1.0 · 2026-08-26
> 前置依赖：Phase 1 ✅（案例库）· Phase 2 ✅（估价引擎 v2 / 后端 API / 房间级标注 / DXF 解析）

---

## 1. 目标与定位

把报价从「系数估算」升级为「**BOM（物料清单）精确报价**」：

| | 快速估算（现有，保留） | BOM 精报（Phase 3 新增） |
|---|---|---|
| 依据 | 单方造价 × 系数 | 逐项 SKU：物料 × 数量 × 印尼本地单价 + 施工人工 |
| 耗时 | 即时 | 即时（引擎自动算量） |
| 精度 | ±20% 参考级 | ±8% 可签约参考级 |
| 输出 | 总价 + 6 项比例 | 总价 + **逐项物料清单**（品牌/规格/数量/单价/供应商） |
| 场景 | 客户自助初筛 | 预约设计师前的深度意向确认 |

**定位原则**：快速估算不动（引流入口），BOM 精报作为「升级结果」叠加展示——客户先看到估算，一键切换查看 BOM 明细。

## 2. 核心设计支点：按空间驱动的算量

已有资产直接复用：

- **231 张照片的 12 类房间标注** → 每种空间类型的标配 SKU 组合有据可依（如"卫浴 = 台盆 + 龙头 + 马桶 + 花洒 + 石材/瓷砖"）
- **DXF 解析输出房间清单**（名称/宽/深/面积）→ BOM 的数量不是估算，是**从图纸算出来的**
- **无图纸时降级**：按房间数 × 空间类型均摊典型面积（如主卧 25㎡、卫浴 6㎡、客厅 50㎡，常量可标定）

## 3. SKU 数据模型（materials 表 v2）

现有 D1 `materials` 表是草稿版，升级为：

| 字段 | 说明 |
|------|------|
| `sku_id` | 唯一编码，如 `STONE-MARBLE-001` |
| `category` / `subcategory` | 大类/子类（见下） |
| `name_id` / `name_en` / `name_zh` | 三语名称（印尼语为主展示） |
| `brand` / `spec` | 品牌 / 规格（如 600×1200mm） |
| `unit` | 计价单位：㎡ / m / 件 / 套 |
| `price_idr` | **印尼本地含税单价（主）** |
| `price_usd` / `price_rmb` | 参考币别（可自动换算） |
| `supplier` / `supplier_contact` | 供应商 / 联系方式 |
| `region` | 价格适用区域（jakarta/bali/surabaya/national） |
| `tier` | 适配档次：standard / luxury / ultra |
| `labor_rate_idr` | 对应安装人工单价（IDR/㎡ 或 IDR/件） |
| `waste_factor` | 损耗系数（石材 1.12 / 瓷砖 1.08 / 涂料 1.05…） |
| `updated_at` / `source` | 价格更新时间与来源（报价单/零售价/电商平台） |

**SKU 大类（v1 覆盖 8 类，每类 3 档）**：

| 大类 | 印尼供应参考 | 典型 SKU 举例 |
|------|-------------|---------------|
| 石材 | CITATAH 等本地大理石商 | 大理石地面 / 门槛石 / 台面 |
| 瓷砖 | Roman、Granit、Platinum | 600×1200 大板 / 厨卫墙砖 |
| 木地板/木饰面 | 本地+进口复合 | 橡木复合地板 / 护墙板 |
| 涂料/微水泥 | Dulux、Jotun、进口微水泥 | 乳胶漆 / 艺术涂料 / 微水泥 |
| 卫浴 | TOTO、American Standard、Kohler | 台盆/马桶/花洒/龙头/浴缸套件 |
| 门窗五金 | 本地铝门窗厂 + 进口五金 | 系统窗 / 室内门 / 锁具 |
| 灯具电气 | Philips、本地灯具商 | 筒灯/灯带/开关面板 |
| 定制柜/软装 | 本地木作工厂 | 衣柜/厨柜/窗帘 |

> ⚠️ 表中价格为**数据采集后的实测值**，本 PRD 不预设数字；首版种子库 50–100 个 SKU。

## 4. BOM 引擎设计

### 4.1 算量规则（quantity rules）

输入：房间清单（来自 DXF 解析或按房间数降级估算）+ 风格 + 档次。

| 物料 | 数量规则 |
|------|----------|
| 地面材料（石材/瓷砖/地板） | Σ 房间面积 × waste_factor |
| 墙面涂料/饰面 | Σ（房间周长 × 层高 2.8m）× 0.85（扣门窗）× waste |
| 卫浴套件 | 卫浴间数 × 套（套件为 SKU 组合包） |
| 门类 | 房间数（不含客厅/开放空间） |
| 灯具 | Σ 房间面积 × 密度常量（如每 4㎡ 一个点位） |
| 定制柜 | 卧室数 × 延米常量（如 3.6 延米/间） |

风格影响 **SKU 选型**（法式 → 石材拼花 + 护墙板；侘寂 → 微水泥 + 藤编），档次影响 **SKU 档位**（standard/luxury/ultra 各档独立 SKU）。

### 4.2 人工费（承接 Phase 2 的施工加权口径）

```
人工费 = Σ（物料数量 × labor_rate_idr）× LABOR_WEIGHT
LABOR_WEIGHT 默认 1.4（与 quote.ts 的 CONSTRUCTION_WEIGHT 同源）
```

> 口径注释：印尼工效能 ≈ 中国产业工人 1/5；纯本地施工 vs 中国工人外派（工签成本高）两种模式都通过 `labor_rate_idr` × `LABOR_WEIGHT` 标定，**后续拿到真实施工报价后重新校准这一个常量即可**。

### 4.3 输出结构

```json
{
  "mode": "bom",
  "total_idr": 0, "total_usd": 0,
  "bom": [
    {"category": "石材", "name": "大理石地面 600×1200", "brand": "CITATAH",
     "quantity": 320, "unit": "㎡", "unit_price_idr": 0, "subtotal_idr": 0,
     "supplier": "...", "room_scope": "全屋地面"}
  ],
  "labor": {"total_idr": 0, "weight": 1.4},
  "estimate_anchor": {"total_idr": 0, "diff_pct": 0}
}
```

`estimate_anchor` 保留系数估算结果做对照——两个数差异 >15% 时提示"建议设计师上门量房复核"。

## 5. 数据采集计划（Phase 3 的真正瓶颈）

| 任务 | 责任方 | 产出 |
|------|--------|------|
| 供应商报价单收集（石材/瓷砖/卫浴/木作） | **业主方**（印尼本地供应商网络） | 报价单照片/PDF |
| 零售参考价采集（Mitra10 / Depo Bangunan / Informa / ACE） | 我们（网页采集整理） | 参考价目表 |
| SKU 结构化录入 + 三语命名 | 我们 | `data/materials.json` → D1 |
| 施工人工单价标定 | 业主方（施工队报价） | labor_rate 常量表 |
| 季度价格更新机制 | 双方 | 每季度首月更新 `updated_at` |

**种子库目标：50–100 个 SKU**（8 大类 × 3 档 × 每档 2–4 个核心 SKU），先覆盖 BOM 金额的 80%（石材+瓷砖+卫浴+地板四类通常占硬装材料费大头）。

## 6. 分阶段交付

| 子阶段 | 内容 | 验收标准 |
|--------|------|----------|
| **3a** | materials 表 v2 迁移 + 种子 SKU 库（50–100 条）+ `/materials` API | API 可按 category/tier 查询，前端可展示材料列表 |
| **3b** | BOM 引擎（`lib/bom.ts` + Worker `/quote?mode=bom`）+ 算量规则 | 300㎡ 标准户型输出完整 BOM，人工复核 3 个案例数量无误 |
| **3c** | 前端 BOM 展示页（/upload 结果区「查看精确物料清单」切换 + 可导出） | 三语 BOM 表格 + 与估算价对照 |
| **3d** | 供应商数据更新工作流（后台录入或 JSON 提报） | 非技术人员可更新价格 |

建议顺序：**3a 先动手（种子库先用公开零售价占位，标注 source）**，业主方供应商数据到位后批量替换。

## 7. 与现有系统的集成点

- `apps/web/lib/quote.ts`：保留系数估算；新增 `lib/bom.ts` 纯函数引擎（常量集中顶部）
- `workers/api-worker`：`/quote` 加 `mode=bom`；新增 `GET /materials?category=&tier=`
- D1：materials 表 v2 迁移（旧表为空，直接重建）
- `schema.sql` 同步更新

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 印尼材料价格数据拿不到/不准 | 先用公开零售价起步（标注来源），业主供应商网络逐步替换；BOM 明确标注"价格为雅加达参考价" |
| SKU 不全导致 BOM 漏项 | v1 只承诺覆盖 8 大类，页面注明"不含家电/园林/特殊定制" |
| 人工费标定偏差 | 单一常量 LABOR_WEIGHT 收口，业主拿到 2-3 个真实施工报价后校准 |
| 价格波动 | updated_at + 季度更新机制；报价输出带"价格有效期"提示 |
